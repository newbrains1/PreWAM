# PreWAM SOLD-template candidate

Independent preview; the existing homepage remains unchanged.

Based on Malte Mosbach's MIT-licensed project-page-template (master), also used by SOLD and derived from F3RM. The template Title, Heading, Abstract and author/container layout are adapted to static HTML. `template.css` retains the compiled Tailwind foundation from the SOLD reference; `prewam.css` adapts the existing PreWAM figures and full comparison tables. No Gatsby runtime is needed for this static preview.

Original template: https://github.com/maltemosbach/project-page-template
Reference: https://slot-latent-dynamics.github.io/

Scientific copy, figures, authors, numerical tables and the sole real-world video come from the existing PreWAM project page. Media is shared through relative links. The preview is marked noindex and does not replace the canonical page.
